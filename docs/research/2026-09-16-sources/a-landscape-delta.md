## 1. Executive Summary

1. 최대 델타는 3개의 초대형 신규 경쟁자: CodeGraph(★71,015/fork 4,560/npm 주간DL 70.9k), GitNexus(★47,362/fork 5,168/DL 49.3k), codebase-memory-mcp(★43,415/fork 3,538/DL 13.7k) — fork 비율(9~16 stars/fork, Serena 자체도 14.75)과 실사용 npm 다운로드가 정상 범위라 유기적 성장으로 판단, 셋 다 베이스라인에 전무.
2. Anthropic 네이티브 `LSP` 도구는 2025-12-19(v2.0.74)부터 존재(베이스라인 누락 사실), 7월 이후 `Piebald-AI/claude-code-lsps` 등 마켓플레이스 플러그인이 rust-analyzer/pyright/gopls 등 24개 언어서버를 `/plugin install` 한 줄로 배선 — 심볼 내비게이션 대체 경로가 열림.
3. JetBrains가 독자 CLI `jbcontext`(JetBrains/context, 2026-07-29 최초 릴리스→v0.9.13 주간 케이던스)로 신규 진입, 기존 `mcp-jetbrains`(2026-01 정지)를 사실상 대체.
4. 표면 축소가 컨센서스화: CodeGraph는 MCP 기본 노출 도구를 단 1개(`codegraph_explore`)로 줄이고 나머지 7개는 env var opt-in — CodeLens의 verb-facade 10개 노출보다 한 단계 더 간 사례.
5. CodeGraph는 자체 벤치마크로 "44% 비용/62% 토큰 절감"과 "세션종료 시 잔존 컨텍스트 +80%"를 같은 페이지에 병기 — CodeLens가 측정한 적 없는 벤치마크 축.
6. Aider는 사실상 정지(마지막 릴리스 2025-08-09, `pushedAt` 2026-05-22) — repo-map 알고리즘은 유효하나 활성 프로젝트로 인용 금지.
7. Serena는 GPL-3.0-or-later 재라이선싱(SolidLSP만 MIT)+CLA 의무화로 채택 장벽 추가.
8. octocode-mcp가 GitHub 리서치 도구에서 `lspGetSemantics`/`localSearchCode` 등 로컬 코드 인텔리전스로 영역을 넓혀 CodeLens와 직접 겹치기 시작.
9. 검증 결과: 27개 프로젝트/항목 중 **21개 1차 소스로 확인, 6개는 UNVERIFIED**(§2 표에 개별 태그, §5에 사유 정리).
